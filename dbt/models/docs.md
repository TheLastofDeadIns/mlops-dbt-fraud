# Антифрод-аналитика на dbt и ClickHouse

Проект строит аналитические витрины по карточным транзакциям с признаком мошенничества.
Данные лежат в ClickHouse в таблице `transactions_db.transactions` из домашки по ClickHouse
(датасет Sparkov с переименованными колонками).

Слои:

| Слой | Модели | Материализация | База ClickHouse |
|------|--------|----------------|-----------------|
| source | `transactions_db.transactions` | сырые данные | `transactions_db` |
| seeds | `states` | таблица | `fraud_dbt_seeds` |
| staging | `stg_transactions` | таблица MergeTree | `fraud_dbt_staging` |
| intermediate | `int_transactions_enriched` | view | `fraud_dbt_intermediate` |
| marts | шесть витрин `mart_*` | таблицы MergeTree | `fraud_dbt_marts` |

Витрины:

- `mart_daily_state_metrics` — дневные метрики по штатам: объём, средний чек, P95, доля крупных транзакций;
- `mart_fraud_by_category` — уровень фрода по категориям покупок;
- `mart_fraud_by_state` — география фрода по штатам;
- `mart_customer_risk_profile` — профиль клиента и сегмент риска HIGH, MEDIUM, LOW;
- `mart_hourly_fraud_pattern` — фрод по дням недели и часам, рискованные окна;
- `mart_merchant_analytics` — оборот и fraud_rate мерчантов, флаг подозрительности.

Граф зависимостей открывается кнопкой в правом нижнем углу страницы.

{% docs source_transactions_db %}
База ClickHouse с сырыми данными из домашки по ClickHouse. Имя базы задаётся переменной `source_schema`,
по умолчанию `transactions_db`.
{% enddocs %}

{% docs stg_transactions %}
Очищенные транзакции, одна строка на транзакцию.

Что делает модель:

- переименовывает сырые колонки и приводит типы;
- снимает технический префикс `fraud_` с названий мерчантов, нормализует регистр категории, пола и штата;
- строит суррогатные ключи транзакции и клиента через `dbt_utils.generate_surrogate_key`;
- удаляет полные дубликаты по ключу транзакции;
- добавляет вычисляемые поля: дату, час, день недели и его название (`dbt_date`), часть суток,
  корзину суммы (макрос `amount_bucket`), флаг крупной суммы и расстояние до мерчанта (макрос `haversine_distance_km`).
{% enddocs %}

{% docs customer_id %}
Суррогатный ключ клиента. В таблице нет номера карты, поэтому клиент определяется по имени, фамилии,
полу и координатам домашнего адреса. На датасете Sparkov такой ключ один к одному совпадает с номером карты.
{% enddocs %}

{% docs amount_bucket %}
Корзина суммы транзакции из макроса `amount_bucket`. Границы задаются переменной `amount_bucket_thresholds`,
по умолчанию `micro` до 10 долларов, `small` от 10 до 50, `medium` от 50 до 200, `large` от 200 до 1000,
`very_large` от 1000.
{% enddocs %}

{% docs is_fraud %}
Признак мошеннической транзакции из колонки `target`: 1 для фрода, 0 для обычной операции.
{% enddocs %}

{% docs fraud_rate %}
Доля мошеннических транзакций в процентах, от 0 до 100: `100 * fraud_txn_count / txn_count`,
округление до четырёх знаков (макрос `safe_pct`).
{% enddocs %}

{% docs risk_segment %}
Сегмент риска клиента по истории транзакций:

- `HIGH` — fraud_rate клиента не ниже `high_risk_fraud_rate_pct` (по умолчанию 2 процента);
- `MEDIUM` — фрод был, но fraud_rate ниже порога;
- `LOW` — мошеннических транзакций не было.
{% enddocs %}

{% docs is_high_risk_window %}
1, если fraud_rate окна день недели x час выше общего fraud_rate не меньше чем в `high_risk_window_lift` раз
(по умолчанию в 2 раза).
{% enddocs %}

{% docs is_suspicious %}
1, если fraud_rate мерчанта выше общего не меньше чем в `suspicious_merchant_lift` раз (по умолчанию в 2 раза)
и у мерчанта не меньше `suspicious_merchant_min_fraud_txn` мошеннических транзакций (по умолчанию 5).
Второе условие отсекает мерчантов, у которых высокий fraud_rate получился из одной-двух операций.
{% enddocs %}

{% docs mart_daily_state_metrics %}
Дневные метрики по штатам, одна строка на пару дата и штат клиента. Количество и сумма транзакций,
средний чек, медиана и P95 суммы, доля крупных транзакций, число и доля фрода.
{% enddocs %}

{% docs mart_fraud_by_category %}
Фрод по категориям покупок, одна строка на категорию. Показывает, в каких категориях мошенничество
встречается чаще всего: число транзакций и фродов, fraud_rate, суммы, доля категории во всём фроде и ранг.
{% enddocs %}

{% docs mart_fraud_by_state %}
География фрода, одна строка на штат клиента. fraud_rate, уникальные клиенты и мерчанты,
сколько из них затронуто фродом, суммы и ранг штата по fraud_rate.
{% enddocs %}

{% docs mart_customer_risk_profile %}
Профиль риска клиента, одна строка на клиента. История транзакций (первая и последняя, активные дни,
категории, мерчанты), средний чек, доля ночных и крупных операций, fraud_rate клиента и сегмент риска.
{% enddocs %}

{% docs mart_hourly_fraud_pattern %}
Временные паттерны фрода, одна строка на пару день недели и час, всего до 168 строк. fraud_rate окна,
во сколько раз он выше общего (lift) и флаг рискованного окна.
{% enddocs %}

{% docs mart_merchant_analytics %}
Аналитика по мерчантам, одна строка на мерчанта. Основная категория, оборот, средний чек, клиенты,
fraud_rate, lift к общему fraud_rate и флаг подозрительного мерчанта.
{% enddocs %}
